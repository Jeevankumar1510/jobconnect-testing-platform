# Backend Resume Studio Templates

Place your resume template files in this folder.

### Supported Template Formats:
1. **HTML/CSS Templates** (`.html`):
   - Place your HTML templates directly in this folder (`resume_studio/templates/`).
   - You can use placeholders like `{{ full_name }}`, `{{ email }}`, `{{ summary }}`, `{{ skills }}`, etc.

2. **Word Document Templates** (`.docx`):
   - Place any `.docx` starter templates here or in `resume_studio/templates/docx/`.

3. **Python Template Renderers** (`.py`):
   - Python code defining template structures, styling configs, and HTML generators.
